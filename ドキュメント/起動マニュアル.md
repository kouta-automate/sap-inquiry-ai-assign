# 起動マニュアル

問い合わせ受付・AI仮アサインシステムの起動手順です。

---

## 前提条件

- **Node.js 18以上** がインストールされていること

```bash
node --version  # v18.x.x 以上であればOK
```

- **CAP CLI** がインストールされていること

```bash
npm install -g @sap/cds-dk
```

---

## 初回セットアップ

```bash
npm install
```

---

## 起動方法

```bash
npm run dev
```

起動成功時のログ：

```
[cds] - serving InquiryService { path: '/odata/v4/InquiryService' }
[cds] - server listening on { url: 'http://localhost:4004' }
```

## AIモード設定

`.env` ファイルで動作モードを切り替えます。

### パターンB：モック（デフォルト・外部接続不要）

```env
USE_MOCK_AI=true
```

AI Coreへの接続なし。固定の分析結果を返す。BTPアカウント不要。

---

### パターンA：Generative AI Hub（実AI接続）✅ 推奨

```env
USE_MOCK_AI=false
AICORE_SERVICE_KEY={"serviceurls":{"AI_API_URL":"..."},"clientid":"...","clientsecret":"...","url":"..."}
AICORE_MODEL_NAME=gpt-4o
```

#### サービスキーの取得手順

1. SAP BTP コックピット → サブアカウントへ移動
2. **Services → Instances and Subscriptions**
3. AI Core インスタンスを選択 → **Service Keys** タブ
4. サービスキーの JSON を **1行に圧縮**して `AICORE_SERVICE_KEY=` に貼り付け

> 詳細は `.env.example` を参照

#### 使用モデルについて

`AICORE_MODEL_NAME` には AI Launchpad でデプロイ済みのモデル名を指定します。

| モデル名 | 説明 |
|---|---|
| `gpt-4o`（デフォルト） | 高精度・推奨 |
| `gpt-4` | 安定版 |
| `gpt-35-turbo` | 高速・低コスト |

## 操作フロー

```
① 問い合わせ入力フォームで内容を入力 → 「送信する」
      ↓
② AI①が問い合わせを分析（数秒〜10秒程度）
   - 要約 / 簡易回答 / 必要スキル / 不足情報
      ↓
③ AI②がメンバーDBからスキル×負荷で候補3名を選定
      ↓
④ 上長承認画面の一覧に「承認待ち」で表示
      ↓
⑤ 行をクリック → 詳細画面でAI分析結果・候補者を確認
      ↓
⑥ 「承認する」ボタンで担当者を確定 → ステータスが「承認済み」になる
```

---

## 注意事項

- **データはサーバー停止とともにリセットされます**（SQLite インメモリ）
- ブラウザで真っ白な場合は **Ctrl+F5**（強制リロード）を試してください
- パターンA使用時、AI処理に数秒〜10秒かかります（LLM応答待ち）
- `.env` ファイルは `.gitignore` に含まれており、リポジトリにはコミットされません

---

## 停止方法

ターミナルで `Ctrl+C` を押してください。
